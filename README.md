## 必要なもの（事前準備）

作業を始める前に、以下のツールをPCにインストールしてください。

| ツール | 説明 | 推奨バージョン |
|--------|------|----------------|
| [Git](https://git-scm.com/) | ソースコードのバージョン管理ツール | 最新版 |
| [Node.js](https://nodejs.org/ja/) | JavaScriptの実行環境 | **18以上** |
| npm | Node.jsに付属するパッケージ管理ツール | Node.jsと一緒にインストールされます |

> **確認方法**: ターミナル（コマンドプロンプト）で以下を実行してバージョンが表示されればOKです。
> ```bash
> git --version
> node --version
> npm --version
> ```

## セットアップ手順

### ステップ1: リポジトリをダウンロードする（クローン）

「クローン」とは、GitHub上のコードを自分のPCにコピーすることです。

```bash
git clone https://github.com/kikuchi08022697209-glitch/BIZ.git
cd BIZ
```

> `cd BIZ` はダウンロードしたフォルダの中に移動するコマンドです。

---

### ステップ2: 必要なパッケージをインストールする

アプリが動くために必要なライブラリ（部品）を一括でインストールします。

```bash
npm install
```

> `node_modules` というフォルダが作成されます。時間がかかることがありますが、そのまま待ちましょう。

---

### ステップ3: 環境変数を設定する

「環境変数」とは、データベースのパスワードやポート番号など、**外部に公開したくない設定値**を書くファイルです。

```bash
cp .env.example .env
```

> Windowsの場合は `copy .env.example .env` を使ってください。

作成された `.env` ファイルをテキストエディタで開き、各項目を自分の環境に合わせて書き換えてください。

| 変数名 | 説明 | 設定例 |
|--------|------|--------|
| `DATABASE_URL` | データベースへの接続先 | `postgresql://user:pass@localhost:5432/biz` |
| `PORT` | アプリを起動するポート番号 | `3000`（ブラウザで `http://localhost:3000` にアクセスできるようになります） |
| `NODE_ENV` | 実行モード | `development`（開発中はこれを使います） |

> `.env` ファイルは **絶対にGitにコミットしないでください**。パスワードなどが漏れる危険があります。（`.gitignore` で除外済みです）

---

### ステップ4: 開発サーバーを起動する

```bash
npm run dev
```

ターミナルに起動メッセージが表示されたら、ブラウザで `http://localhost:3000` を開いてください。

## 本番環境向けビルド

開発が完了し、本番公開する際は以下のコマンドを使います。

```bash

# ビルド後のアプリを起動する

```

## テストの実行

テストとは、コードが正しく動くかを自動で確認する仕組みです。

```bash
# テストを1回実行する
npm test

# ファイルを保存するたびに自動でテストを実行する（開発中に便利）
npm run test:watch
```

## ブランチについて

「ブランチ」とは、コードの作業ラインを分けて管理する仕組みです。
複数人で開発する際に、お互いの作業を干渉させないために使います。

| ブランチ名 | 役割 |
|------------|------|
| `main` | 本番リリース用。直接コミットしません |
| `develop` | 開発者全員が統合するブランチ |
| `feature/機能名` | 新機能を開発するときに `develop` から作成します |
| `fix/修正内容` | バグ修正のときに作成します |

> **基本的な流れ**: `develop` から `feature/*` ブランチを作成 → 開発 → `develop` にマージ → `main` へリリース

## よくあるエラーと対処法

**`npm install` でエラーが出る**
- Node.jsのバージョンが18以上かどうか確認してください（`node --version`）

**サーバーが起動しない**
- `.env` ファイルが存在するか確認してください
- `PORT` が他のアプリと競合していないか確認してください

**データベースに接続できない**
- `DATABASE_URL` の値が正しいか確認してください
- データベースサーバーが起動しているか確認してください
